    Pasang ekstensi browser

    Dengan ekstensi, klik download di Chrome atau Edge langsung masuk ke Sedot. Cukup sekali, dan ekstensinya ikut ter-update bersama aplikasi.

    1. (biarkan jendelanya terbuka)
    2. Di browser, ketik chrome://extensions (Edge: edge://extensions) di kolom alamat
    3. Nyalakan Developer mode (Chrome: kanan atas · Edge: menu kiri)
    4. Klik Load unpacked, lalu pilih folder dari langkah 1
